---
title: Register the routes
description: Mount OAuth endpoints and discovery metadata at the correct paths.
---

Add the OAuth routes in `start/routes.ts`:

```ts title="start/routes.ts"
import router from '@adonisjs/core/services/router'
import sesame from '@julr/sesame/services/main'

router
	.group(() => {
		sesame.registerRoutes()
	})
	.prefix('/oauth')

sesame.registerDiscoveryRoutes()
```

Call `registerRoutes()` without a router argument. Keep discovery registration outside the prefixed group.

Do not apply session authentication middleware to the whole OAuth group. The token, introspection, revocation, and registration endpoints need to accept requests without a browser session.

If your application uses CSRF protection, configure its exceptions for endpoints that external OAuth clients call. Keep CSRF protection on your browser consent submission.

## Change the JWKS path

To expose the public signing key at another path, pass `jwksPath`:

```ts
sesame.registerDiscoveryRoutes({ jwksPath: '/.well-known/jwks.json' })
```

## Verify discovery

With the application running, request its metadata:

```bash
curl http://localhost:3333/.well-known/oauth-authorization-server
```

The response describes the issuer, endpoint URLs, supported scopes, grants, and prompts. Confirm that the URLs use your public issuer and intended route prefix.

See the [endpoint reference](/reference/endpoints/) for the registered methods and paths. For per-resource metadata, [configure MCP discovery](/guides/mcp/).
