title: Configure the server
description: Set the issuer, storage driver, scopes, and browser pages.

After [installation](/guides/getting-started/), edit `config/sesame.ts`.

## Set the issuer and pages

Validate `APP_URL` in `start/env.ts` and set it to the public URL of your authorization server. Use HTTPS in production. A frontend URL or `0.0.0.0` bind address is not the issuer.

Define the store and the browser pages:

```ts title="config/sesame.ts"
import env from '#start/env'
import { defineConfig, stores } from '@julr/sesame'
import type { InferScopes } from '@julr/sesame/types'

const sesameConfig = defineConfig({
	issuer: env.get('APP_URL'),
	store: stores.lucid(),
	scopes: {
		read: 'Read access',
		write: 'Write access',
	},
	defaultScopes: ['read'],
	grantTypes: ['authorization_code', 'refresh_token'],
	loginPage: '/login',
	consentPage: '/oauth/consent',
})

export default sesameConfig

declare module '@julr/sesame/types' {
	interface SesameScopes extends InferScopes<typeof sesameConfig> {}
}
```

For Kysely, replace `stores.lucid()` with [your Kysely store configuration](/guides/install-kysely/#connect-your-database).

The module augmentation lets TypeScript check your declared scope names in middleware and guard calls.

## Adjust token lifetimes

If the defaults do not fit your application, add duration strings to the config:

```ts
accessTokenTtl: '30m',
refreshTokenTtl: '14d',
authorizationCodeTtl: '5m',
authorizationRequestTtl: '10m',
```

Set `refreshTokenRotationGracePeriod: 0` if you require strict refresh token reuse detection. Read [refresh token rotation](/explanations/token-lifecycle/) before changing that setting.
