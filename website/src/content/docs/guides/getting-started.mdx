description: Choose a storage driver and connect Sésame to your AdonisJS application.
---

Sésame adds an OAuth authorization server to an AdonisJS application. Your application supplies the user accounts, login page, and consent page.

Start with the installation guide for your database layer:

- [Install with Lucid](/guides/install-lucid/) for applications that use Lucid models and migrations.
- [Install with Kysely](/guides/install-kysely/) for applications that use a Kysely connection, including applications without Lucid.
- [Upgrade from 0.6 to 0.7](/guides/migrate-to-0-7/) for existing installations.

After installation, complete these tasks in order:

1. [Configure the server](/guides/configure-server/).
2. [Register the routes](/guides/register-routes/).
3. [Create a client](/guides/manage-clients/).
4. [Connect login and consent](/guides/login-and-consent/).
5. [Protect your API](/guides/protect-api/).

For identity claims, [enable OpenID Connect](/guides/enable-oidc/). For service accounts, [issue a client credentials token](/guides/client-credentials/).
